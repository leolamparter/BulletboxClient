# Bulletbox 26.1.1-01g
### The Launcher & Integration Update

**Dedicated Launcher Application (26.1.1-01g.1)**
* **Unified Entry Point:** Introduced a standalone Raylib-based launcher to manage game updates and client execution.
* **Styled Patch Notes:** Implemented a "Markdown-lite" rendering engine that supports headers (#, ##, ###) and automatic word-wrapping.
* **Advanced Scrolling logic:** Added a scrollable container for changelogs using Scissor Mode for clean text clipping and mouse-wheel support with friction-based smoothing.
* **Visual Identity:** Designed a themed interface featuring the signature "Bulletbox Yellow" and cyan borders.

**Process Management & Path Resolution (26.1.1-01g.2)**
* **Smart Binary Discovery:** Implemented an absolute path resolution system that searches for the `BulletboxClient` executable across multiple project directory structures.
* **Working Directory Context:** Fixed a critical bug where the client would fail to load resources (textures/fonts) because it was inheriting the launcher's folder context. The launcher now correctly sets the `WorkingDirectory` to the project root.
* **Automated Lifecycle:** Configured the launcher to automatically close upon successful game hand-off to save system resources.

**UI & Asset Refinement (26.1.1-01g.3)**
* **Health Bar Optimization:** Refactored the `HealthBar` component to use the centralized `AssetManager` for texture retrieval, eliminating redundant `LoadTexture` calls.
* **Resource Loading Safety:** Added safety checks to UI rendering to prevent crashes if texture IDs are null or paths are temporarily unreachable.
* **Error Reporting:** Integrated a real-time error display in the launcher UI to notify users of missing binaries or build issues.

**Technical Improvements (26.1.1-01g.4)**
* **Text Rendering Cache:** Optimized the launcher main loop to cache wrapped text lines, preventing frame-rate drops during window resizing.
* **Directory Traversal:** Added logic to "walk up" the file tree from the binary to find the `resources/` directory, ensuring portability.

**Notes**
* Ensure `dotnet build` has been run in the `BulletboxClient` directory before attempting to launch.
* The launcher currently defaults to connecting to `127.0.0.1:32308`.
* Future updates will include a toggle to start a local server instance directly from the UI.
