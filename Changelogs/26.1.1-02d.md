# Bulletbox 26.1.1-02d
## The Ambience & Adversaries Update

# New Sounds (26.1.1-02d.1)
- Added shield block and sword swing sounds. (26.1.1-02d.1/1)
- Added a sound for the raid countdown. (26.1.1-02d.1/2)
- Added a sound for an entity dying, the player killing an entity, and the player dying. (26.1.1-02d.1/3)
- Added footstep sounds for all 8 biomes. (26.1.1-02d.1/4)

# Raiders (26.1.1-02d.2)
- The default raider is now called a "Raidshroomer" to allow other types of raiders in the future. (26.1.1-02d.2/1)
- Raidshroomers now have their own texture for: idle, angry, and afraid. (26.1.1-02d.2/2)
- Raidshroomers can now only reach 80% of the player's base reach (26.1.1-02d.2/3)
- Raidshroomers now only spawn with swords. (26.1.1-02d.2/4)
- Raidshroomers now give the player a Raidshroom upon death. (26.1.1-02d.2/5)

# Features (Trees, Springs, Tumbleweeds, etc.) Generation (26.1.1-02d.3)
- All features are now forced to generate at least 3 chunks away from each other. (26.1.1-02d.3/1)
- All features' generation chances have been doubled to keep areas dense as before. (26.1.1-02d.3/2)
- Features now render top-to-bottom instead of randomly. (26.1.1-02d.3/3)

# Rivers (26.1.1-02d.4)
- Rivers now have a range for the color of each chunk to be slightly different. (26.1.1-02d.4/3)
- River colors reroll every 0.8 - 1.2 seconds. (26.1.1-02d.4/4)

# Technical Changes (26.1.1-02d.5)
- Added a new AddItem function. (26.1.1-02d.5/1)
- Added a new ItemStack dictionary for item names. (26.1.1-02d.5/2)
- Non-weapon items don't have their textures rotated anymore. (26.1.1-02d.5/3)
- A new Bulletbox Studios splash screen shows whenever textures are loaded and on game start. (26.1.1-02d.5/4)
- Added a two new textures in resources/textures/item/raidshroom.png and resources/textures/ui/other/bbstudios.png. (26.1.1-02d.5/5)
