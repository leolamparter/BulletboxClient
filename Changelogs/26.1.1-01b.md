# Bulletbox 26.1.1-01b
### The Combat & Networking Update

**Networking Infrastructure (26.1.1-01b.1)**
* **Client-Server Communication:** Implemented a robust TCP-based architecture allowing for persistent multi-user connections and data streaming. (26.1.1-01b.1/1)
* **Packet-Based Protocol:** Established a standardized communication layer using Packet IDs for discrete actions like movement, login, and combat. (26.1.1-01b.1/2)
* **Real-time Synchronization:** Enabled position broadcasting so that all connected clients see other players moving in the world. (26.1.1-01b.1/3)

**Combat System (26.1.1-01b.2)**
* **Weapon Statistics Engine:** Introduced a global library defining base damage, cooldowns, and range for Swords, Axes, Daggers, Spears, Scythes, and Kanabos. (26.1.1-01b.2/1)
* **Dynamic Math Formulas:** Implemented non-linear scaling for combat logic, where damage and knockback are calculated based on the weapon's charge percentage. (26.1.1-01b.2/2)
* **Physics-Based Knockback:** Replaced static coordinate updates with a smooth, velocity-based knockback system that uses friction decay for a natural physical feel. (26.1.1-01b.2/3)
* **Dagger Combo Mechanics:** Added specialized logic for high-speed weapons, including exponential combo decay and attack speed penalties. (26.1.1-01b.2/4)

**Inventory & Hotbar (26.1.1-01b.3)**
* **Server-Authoritative Inventory:** Implemented the `ItemStack` system where the server maintains the "Source of Truth" for all player items. (26.1.1-01b.3/1)
* **Hotbar Selection:** Players can now select active weapon slots using number keys (1-6), with the server tracking the "Held Item" for combat validation. (26.1.1-01b.3/2)
* **Item Movement Logic:** Added functionality to swap items between slots, synchronizing the changes across the network. (26.1.1-01b.3/3)

**Health & State Management (26.1.1-01b.4)**
* **Health Synchronization:** Implemented a dedicated sync packet that updates the client HUD whenever damage or healing occurs on the server. (26.1.1-01b.4/1)
* **Death & Respawn Logic:** Created basic server-side handling for player health reaching zero, including console logging and stat resets. (26.1.1-01b.4/2)

**UI & Visual Enhancements (26.1.1-01b.5)**
* **Visual HUD:** Added a persistent health bar and a modular hotbar UI to the main gameplay screen. (26.1.1-01b.5/1)
* **Attack Charge Indicator:** Implemented a dynamic UI bar that tracks weapon cooldowns and indicates the 35% minimum attack threshold. (26.1.1-01b.5/2)
* **Interactive Inventory Menu:** Created a visual grid system for managing player items, including placeholder rendering and count displays. (26.1.1-01b.5/3)
* **Smooth Camera Lerp:** Integrated the CameraManager to ensure the viewport follows the player smoothly even during rapid knockback events. (26.1.1-01b.5/4)
