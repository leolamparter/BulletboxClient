# Bulletbox 26.1.1-01c
## The Texturing Update Part 1

* **Asset Management System:** Introduced a centralized loader for HD textures to optimize VRAM usage and enable high-fidelity sprite rendering. (26.1.1-01c.1/1)
* **Player Animation System:** Implemented a 2-frame, 4 FPS animation for player characters using a 64x128px spritesheet. (26.1.1-01c.1/2)
* **Iterative Asset Pipeline:** Established a workflow for upscaling 16x16 pixel art prototypes into HD entity textures. (26.1.1-01c.1/3)
* **Asset Loading Diagnostics:** Added console logging to verify successful texture loading and assist in debugging asset path issues. (26.1.1-01c.1/4)
* **Debug Utility System:** Added a toggleable hitbox visualization tool (Grave + H) for development and hit-reg testing. (26.1.1-01c.1/5)
* **Options System:** Introduced a dedicated Options screen featuring a persistent FOV/Zoom slider to customize visual perspective. (26.1.1-01c.1/6)
* **Namespace Resolution:** Ensured proper access to namespaced classes (e.g., `Settings`) from global namespace files. (26.1.1-01c.1/7)
* **Camera Zoom Abstraction:** Implemented a dedicated `Zoom` property on `CameraManager` to control the camera's field of view, resolving direct access errors. (26.1.1-01c.1/8)
