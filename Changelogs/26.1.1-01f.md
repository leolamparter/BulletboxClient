
# Bulletbox Changelog

## Version 26.1.1-01f - Biome System Prototype

### Added
- Entirely new biome system for the world.
- The world is now divided into small square chunks, each assigned a biome.
- Two surface biomes implemented: Meadow and Forest.
- Server dynamically generates and stores biome data for each chunk.
- Client requests chunk data as the player moves, supporting infinite world generation.
- Chunks are rendered on the client as colored regions: light green for Meadow, dark green for Forest.
- Biome assignment uses Perlin noise for smooth, natural transitions and large contiguous regions.
- Modular and scalable design for easy future biome and terrain expansion.

### Technical
- Added a Perlin noise implementation to the server for procedural biome generation.
- Biome data is generated deterministically from chunk coordinates, no need to store all chunks forever.
- Simple client-server protocol for chunk requests and responses.

### Notes
- This is a prototype: no terrain, trees, blending visuals, or additional biomes yet.
- Adjust the Perlin noise scale in `World.cs` to control biome region size and smoothness.
