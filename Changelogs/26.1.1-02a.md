# Bulletbox 26.1.1-02a

### The Singleplayer & Discovery Update

## **Core Systems**
* **Singleplayer Mode Foundation:** Added the ability to launch directly into the game world without a remote server connection.
* **Integrated World Generation:** Singleplayer now utilizes the same chunk-based procedural logic as the server, ensuring parity between game modes.
* **World Save Hook:** Implemented early logic for serializing world chunks to local disk, allowing for persistent singleplayer progress.

## **Networking & Social**
* **Local Mode Toggle:** Added a network bypass that allows the game to function without a TCP/IP handshake, preventing "Packet Null" errors during offline play.
* **Friends List UI:** Added a placeholder for the upcoming Friends List and Social Hub, accessible from the main menu.
* **LAN & P2P Preparation:** Refactored connection logic to support future Peer-to-Peer "Open to LAN" functionality.

## **Visuals & UX**
* **Biome Color Remaster:** Completely overhauled the color palette for all biomes. Colors are now more muted and natural, reducing eye strain and improving the visibility of player/enemy models.
* **Menu Reorganization:** Redesigned the Home Screen to accommodate the growing list of play modes and social features.
* **Dynamic UI Scaling:** Menu buttons now feature improved vertical spacing to handle the new "Singleplayer" and "Friends" entries.

## **Technical Notes**
* Singleplayer currently functions as a "Local Client" mode. In future builds, this will be fully upgraded to an "Internal Server" to allow for seamless transition into LAN/P2P play.
* Biome blending algorithms have been tuned to account for the new, softer color values.
